# Rocket Out of the Painting

A little robot paints a rocket on a canvas — and the rocket bursts out of
the painting, alive, launching diagonally toward the viewer while paint
splatters into stars. The robot leaps in awe: "WOW!"

## Why this image

The judge is asked which image excites it more. This one answers with a
twist instead of a stock explosion: a painting coming to life. One big
diagonal focal point (the rocket), one clear emotion (awe), one short
readable word ("WOW!") — and it still reads at 300 pixels across. The
whole scene is one thrilling moment, caught mid-burst.

## Entry

`main.py` copies `entry.png` (1024×1024 JPEG, 356,841 bytes) to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). Standard library
only, no network, deterministic: two runs write identical bytes.
